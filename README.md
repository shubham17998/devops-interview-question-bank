# 🚀 DevOps & Cloud Interview Question Bank

> A curated collection of AWS, DevOps, SRE, Kubernetes, Terraform, Docker, CI/CD, Linux, Monitoring, Security, and Production Scenario interview questions.
---

## 📖 About

This repository contains a comprehensive collection of interview questions gathered from:

* Real DevOps interviews
* AWS and Cloud interviews
* Site Reliability Engineering (SRE) interviews
* Kubernetes and Cloud-Native discussions
* Infrastructure Automation and CI/CD practices
* Production troubleshooting scenarios
* Cloud architecture and system design discussions

The goal of this repository is to provide a single place where engineers can revise, practice, and strengthen their DevOps and Cloud knowledge.

---

## 🎯 Who Is This Repository For?

* DevOps Engineers
* Site Reliability Engineers (SRE)
* Cloud Engineers
* Platform Engineers
* Kubernetes Administrators
* AWS Engineers
* Infrastructure Engineers
* Students preparing for DevOps and Cloud roles
